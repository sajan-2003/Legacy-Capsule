# Memory Diary App

A private digital diary app for securely saving daily memories with optional future time-lock features. Built with Flutter, this app focuses on privacy, emotional value, and long-term memory preservation.

---

## Overview

Memory Diary is designed for people who want a safe and personal place to store their life moments. Unlike social media, this app is completely private. Users can save their day-to-day memories as photos, videos, voice notes, and text. Special memories can be locked and unlocked in the future.

This project is suitable for:

* Students (Final Year / Mini Project)
* Personal learning
* Future startup development

---

## Key Features

* Private day-to-day memory timeline with date and time-based view
* Support for multiple memory types: photo, video, audio, and text
* Future time-lock to unlock selected memories at a later date
* Trusted receivers (optional) for controlled future sharing
* Biometric security using fingerprint or Face ID
* Cloud and local secure storage for reliable data handling
* Abuse and safety controls for platform protection

---

## Tech Stack

* Frontend: Flutter (Dart)
* Authentication: Firebase Auth
* Database: Firebase Firestore
* Media Storage: Firebase Cloud Storage
* Local Secure Storage: flutter_secure_storage
* Biometric Login: local_auth
* Version Control: Git and GitHub

## Getting Started

### Prerequisites

* Flutter SDK installed
* Android Studio or VS Code
* Firebase project setup
* Git installed

---

### Clone the Repository

```
git clone https://github.com/sajan-2003/Legacy-Capsule.git
cd Legacy-Capsule
```

---

### Install Dependencies

```
flutter pub get
```

---

### Run the App

```
flutter run
```
